System requirements

Operating systemWindows 10 or 11 (64-bit)
Disk space~1 GB for the application, plus room for your project images
PythonNot required — everything is bundled
InternetNot required. HerpetoID never uploads your photographs

Installing

  1. Download the .zip above.
  2. Right-click it → Extract All, and choose where to keep it (for example C:\Programs\HerpetoID). Avoid running it from inside the zip.
  3. Open the extracted folder and run HerpetoID.exe.

There is no installer and nothing is written to the registry. To uninstall, delete the folder.

Windows may warn you the first time. The build is not code-signed yet — a signing certificate is an annual cost this project does not carry. If SmartScreen shows “Windows protected your PC”, click More info → Run anyway. You can verify exactly what you are running: the source is public and the release is built from it.

Species add-ons

Support for each amphibian or reptile species ships as a plugin, as do the matching algorithms — drop them into the plugins/ folder next to the application and restart. New modules are announced on the news page as they are released. Writing one for your own study species is documented in the repository.

Running from source

Prefer to run the development version, or use another operating system? HerpetoID is a Python 3.12 application; the packaged build is Windows-only, but the source is not. 

git clone https://github.com/{{ site.repository }}.git
cd HerpetoID
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"
herpetoid

Full instructions live in the repository README. Found a problem? Open an issue.
