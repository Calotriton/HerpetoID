# Projects

A **project** is a portable folder (a "bundle") that contains everything for one study:

```
MyStudy/
  project.db        the database (individuals, observations, measurements)
  images/           original observation images
  thumbnails/       generated thumbnails
  descriptors/      computed feature files
  README.txt        a note describing the bundle
```

## Creating and opening

- **New Project…** — choose an empty folder and give the project a name.
- **Open Project…** — select an existing project folder.
- Recently used projects are listed for quick access; double-click to open.

Because a project is just a folder, you can copy it to another computer, put it on a shared drive, or
archive it. Open it anywhere with **Open Project…**.
